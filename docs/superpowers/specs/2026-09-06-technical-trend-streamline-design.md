# 日线波段技术趋势工具：精简设计

状态：用户以 `go` 确认，已实施并通过工程验收；经济有效性未验证。日期：2026-09-06。

用户已确定持有周期为数周至数月，并明确授权引入技术指标，取代原先仅限裸K的产品方向。实现时更新 AGENTS.md；保留现有 CLI 名称，避免无意义重命名。

## 目标与判断边界

回答当前趋势方向、强度、所处位置、成立与失效条件，以及交易计划风险。工程验收与经济有效性分别报告；未经样本外检验的参数不称为最优，规则等级不称为胜率。

采用“精简趋势引擎”方案。另两种方案为只增加指标面板（无法消除旧逻辑冲突），或建立全面多指标评分系统（重复证据和调参空间过大），均不采用。

## 保留、移除和迁移

保留：显式 ticker 输入、行情源降级、复权元数据、数据质量审计、完整K线过滤、UTC内部时间、已确认摆动高低点与支撑压力、ATR风险预算、结构化报告和日志。

主链路移除：Smart Money身份推断及双证据融合、分钟资金流代理、未校准置信评分、单根K线决定动作、多套重复趋势解读、AI交易助手及两轮新闻改变动作的逻辑。相关无调用代码和专属测试一起删除；历史 reports/ 与已有日志不删除。

新闻只保留可选的日期、来源链接和标题事实附录；不调用LLM，不生成新闻方向、概率或交易动作。复用现有采集与过滤能力，删除仅服务模型综合的路径。旧LLM选项明确报迁移提示，不能静默忽略用户参数。

价格区域保留已确认结构支撑压力与锚定VWAP；删除用日K分摊成交量构建的POC/价值区、买卖方流动性身份标签。锚定VWAP标注为OHLCV典型价近似值，不声称是真实机构成本。

## 最小指标集合

| 指标 | 用途 | 规则边界 |
| --- | --- | --- |
| EMA20/50/200 | 短期位置、中期趋势、长期背景 | 三条线作为同一类趋势信息，不分别投票 |
| ADX14 | 趋势强度 | 不提供方向；20/25是描述性惯例，首版不硬性拦截交易 |
| ATR14及ATR% | 波动、入场偏离、止损与仓位 | Wilder平滑；首值为14个TR均值，跳空计入TR |
| 前20日高低通道 | 突破、结构边界 | 严格排除当天数据，以完整日K收盘确认 |
| 相对成交量 | 突破参与程度 | 当日量/之前20个完整交易日均量；缺量则不可计算 |
| 锚定VWAP | 距已确认结构锚点的位置 | 标明锚点和确认日期；只作辅助，不独立发出买卖动作 |

复用 pandas/numpy，无新指标依赖。EMA以首N根收盘均值初始化，再按2/(N+1)递推；不足N根返回不可计算。ADX采用Wilder平滑和明确的初始化，零振幅序列返回零强度，不产生NaN/Inf。所有中间计算保留精度，仅展示时四舍五入。

MACD、RSI、KDJ、布林带首版不引入：当前目标已有方向、强度和波动信息，新增指标必须先展示增量效果。

## 趋势状态与执行规则

输入只含当时已收盘K线。先判数据是否足够，再输出上涨、下跌、过渡三个方向状态，并单独显示强度、突破与回撤位置。

- 上涨：Close > EMA50 > EMA200，且EMA50高于5个交易日前。
- 下跌：Close < EMA50 < EMA200，且EMA50低于5个交易日前。
- 其余为过渡；ADX低于20单独显示趋势弱，不能把所有低ADX状态称为横盘。
- 不足205根完整日K不生成完整趋势方向和新仓建议；仍可展示已具备样本的指标与结构。默认请求足够长的历史，数据源无法覆盖时明确降级。
- 唯一首版新仓剧本：上涨状态下，首次收盘突破前20日最高价；同一突破持续期间不反复建仓。EMA20用于显示位置和过度偏离，不新增回撤买点规则。
- 候选计划最早下一交易日开盘执行。入场价格超过信号收盘+0.5ATR，或相对信号EMA20偏离超过2ATR，跳过该次入场；实际开盘价格不满足止损、首个压力区下沿空间约束时也跳过。
- 初始止损为信号日之前20日最低价减0.5ATR；若距离过大，按实际单股风险减小仓位。入场后使用前20日低点减0.5ATR的结构移动止损，只能上移，不能放宽。
- 结构压力只展示为观察位；若存在上方压力且首个压力区下沿距离不足1R，则不新开仓；没有压力位不虚构目标，不将1R/2R/3R风险刻度称为预测目标。
- 收盘跌破EMA50或趋势转为下跌，已有多头在下一交易日开盘退出；没有持仓时只输出防守状态，绝不产生做空交易。
- 不限持有天数；趋势退出与移动止损决定持有期，符合数周至数月的目标。报告明确区分趋势判断、候选信号、实际成交、已有持仓处理。

这些是冻结的首版研究规则，不是已验证的最优参数。ADX、成交量和VWAP仅作为观察信息，不能为了让所有指标“有用”而任意增加交易过滤器。

## 风控与报告

复用单股风险/账户风险计算，建议仓位和真实持仓分开。可选账户状态JSON提供实际仓位、账户回撤和连续亏损；缺失时标记账户风控不可评估，不宣称账户风险正常。账户状态为只读输入，不连接券商、不下单。

报告按标的输出：数据日期及质量、趋势方向与强度、指标数值及解释、支撑压力、候选计划与失效条件、风险预算和账户状态。保留Markdown、JSON、journal和audit，输出新schema版本；旧日志仍可读取，旧字段不回写重算。

## 验证与回测

在线与历史回测复用同一个纯趋势/信号函数。历史日K逐日推进；若使用周线上下文，从当前日线前缀构建已完成周线，不截取预先包含未来价格的周/月K。

回测为单标的long/cash状态机：无重复仓位，包含多日持仓、次日开盘入场/趋势退出、真实开盘跳空止损、盘中止损、单边费用和滑点。无法由OHLC推断的同日路径采用明确保守规则；不宣称能够精确复现成交。交易成本必须显式提供；零成本结果标注为毛收益研究。

删除将减仓/回避当做空的路径、下一根K强制结算、按交易数缩放的伪年化Sharpe及最终收益不变的Monte Carlo收益分位。账户指标用逐日净值计算；没有基准数据时超额收益不可计算，不填零。

对照为同标的买入持有，以及更简单的EMA50/200 long/cash规则。按时间划分训练/验证/测试且测试窗不重叠，冻结规则，不自动寻优。先完成可运行验证能力和样例，不以单次回测宣称具备盈利优势；真实跨市场经济验证独立列出数据范围、成本、样本数和限制。
