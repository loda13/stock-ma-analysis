# v4.0.0 — 日线波段趋势分析

本次将工具从裸K与AI叙事系统精简为日线波段趋势评估，服务数周至数月的持有周期。报告与离线回测共享确定性信号规则。

## 核心变化

- EMA20/50/200判断趋势与位置，ADX14描述强度，ATR14衡量波动和止损距离；前20日通道识别首次收盘突破，相对成交量提供辅助观察。
- 保留已确认的支撑压力、明确锚点的近似VWAP、行情降级与复权检查、日志和审计。
- 删除主力意图、日K推算成交分布、重复评分和AI买卖方向。可选新闻只展示来源、日期、标题。
- 区分候选预算与真实持仓，支持日期明确的只读账户快照；处理已有保护价被跌破、信号过期和组合风险上限。
- 回测改为只做多或持币，支持多日持仓、下一交易日开盘执行、跳空止损、费用与滑点、收盘持仓暴露和期末未平仓记录。
- 增加买入持有、EMA规则对照，以及参数冻结的非重叠滚动验证。独立窗口合成收益不等于连续可交易账户收益。

## 升级须知

这是不兼容升级，建议先备份自己的配置与调用脚本。

1. CLI入口仍为 `python naked_k_analysis.py 0700.HK`，必须显式传入标的。
2. 移除 `--llm`、`--llm-base-url`、`--llm-model`、`--news-model`。`--news`仅保留事实附录。
3. 配置移除 `smart_money`，请按 `config.example.json` 迁移。可选账户输入参照 `account.example.json`，不要直接使用示例持仓。
4. 报告和新日志使用 `technical-trend-v1` schema；旧Python advisor接口已移除。旧日志保留，但不能混作同一策略的业绩记录。
5. 回测必须显式提供手续费和滑点，输出位于 `reports/`；未提供外部基准时超额收益为null。

```bash
python naked_k_analysis.py 0700.HK TSLA --json
python naked_k_backtest.py 0700.HK --csv daily.csv --commission-bps 10 --slippage-bps 10 --output reports/backtest.json
```

示例费用不代表任何市场的实际费用。CSV需要完整且按日期升序的OHLCV，至少206根日K才能评估第一个执行日。

## 验证与边界

260项离线测试、独立代码审查、报告/JSON/日志/审计端到端样例以及回测CLI验证通过。移除的旧模块测试随模块删除，行情、新闻与风险相关回归覆盖保留。

规则经济有效性仍为 **UNVALIDATED**。合成行情与工程测试不证明收益优势；交易日历、停牌、涨跌停、整手和点时复权等仍需核对。工具不连接券商，也不执行交易。
